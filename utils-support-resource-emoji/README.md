# utils-support-resource-emoji

Emoji 数据文件（emoji.json.xz）

---

## 快速开始

### 1. 添加依赖

```xml
<dependency>
    <groupId>com.chua</groupId>
    <artifactId>utils-support-resource-emoji</artifactId>
    <version>${project.version}</version>
</dependency>
```

## 配置说明

本模块为零配置模块，引入依赖后即可使用。
