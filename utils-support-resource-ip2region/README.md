# utils-support-resource-ip2region

ip2region IPv4 定位数据库（ip2region.xdb），约 11MB

---

## 快速开始

### 1. 添加依赖

```xml
<dependency>
    <groupId>com.chua</groupId>
    <artifactId>utils-support-resource-ip2region</artifactId>
    <version>${project.version}</version>
</dependency>
```

---

## 配置说明

本模块为零配置模块，引入依赖后即可使用。
