# utils-support-resource-geonames

GeoNames 中国地名数据（CN.zip），约 31MB，用于逆地理编码

---

## 快速开始

### 1. 添加依赖

```xml
<dependency>
    <groupId>com.chua</groupId>
    <artifactId>utils-support-resource-geonames</artifactId>
    <version>${project.version}</version>
</dependency>
```

---

## 配置说明

本模块为零配置模块，引入依赖后即可使用。
